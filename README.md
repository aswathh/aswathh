## 🏢 What I Do at TCS — Project INTEL

At **AI CoE Labs, TCS Kochi**, I work on **INTEL**, where we focus on making AI models smaller, faster, and production-ready for inference:

- ⚡ **Model optimization** — converting and optimizing models for efficient inference with **OpenVINO**
- 📉 **Compression** — quantization and performance tuning to cut latency and memory footprint
- 🚀 **Inferencing** — benchmarking and deploying optimized models across Intel hardware
- 🔬 **Experimentation** — comparing frameworks and tools to find the best accuracy / speed trade-off
